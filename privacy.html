Privacy Policy

Personal Calendar Assistant · Last updated 23 October 2026

This policy explains how Personal Calendar Assistant ("the app") accesses, uses, stores and shares Google user data. The app is a private, self-hosted tool operated by a single individual for his own personal scheduling.

1. What Google user data the app accesses

  • Google Calendar data — calendar list, event titles, descriptions, times, locations and attendees, via the https://www.googleapis.com/auth/calendar scope.
  • Basic account identifier — the email address of the authorising account, used only to identify which calendar account is connected.

The app does not request Gmail, Drive, Contacts, Photos or any other Google data.

2. How the data is used

  • To read upcoming events so the operator can be reminded of appointments, school activities and family schedules.
  • To create or delete calendar events when the operator explicitly instructs the app to do so.
  • To verify that the authorised connection is still active.

The data is used solely to provide these calendar features to the operator. It is never used for advertising, profiling, or any secondary purpose.

3. How the data is stored

  • Data is stored only on hardware owned and controlled by the operator (a personally owned single-board computer on a private home network).
  • OAuth access and refresh tokens are stored in a local file readable only by the operator's own system account.
  • Event information is held only in memory or in local notes during use. It is not uploaded to any cloud database.

4. How the data is shared

The app does not share, sell, rent or transfer Google user data to any third party. No analytics, advertising, or tracking services are used. No human reads the data other than the operator himself.

Limited exception: if the operator asks the assistant for a written summary, the relevant event details may be passed to the large-language-model provider that powers the assistant, strictly to generate that reply. No data is used to train models, and no data is retained by that provider beyond processing the request.

5. Data retention and deletion

  • Calendar data is not retained after it is no longer needed for a reminder or task.
  • The operator can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored tokens.
  • Deleting the local token file removes all stored credentials from the device.

6. Security

Access is protected by Google OAuth 2.0. Tokens never leave the operator's device. The device is not exposed to the public internet and requires authenticated access.

7. Limited Use compliance

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide the user-facing features described above.
  • Google user data is not transferred to third parties except as necessary to provide those features, for security purposes, or to comply with applicable law.
  • Google user data is not used for serving advertisements.
  • No human reads Google user data except the operator, whose data it is.

8. Children

The app is not directed at children and is not offered to the public.

9. Changes to this policy

Any changes will be published on this page with an updated revision date.
