Personal Calendar Assistant

A private, single-user Google Calendar helper

What this app does

Personal Calendar Assistant is a self-hosted assistant that runs on a Raspberry Pi owned by its operator. It connects to the operator's own Google Calendar account to:

  • Read upcoming events across the operator's calendars so the assistant can remind him about appointments, school events, and family schedules.
  • Create and delete events on those calendars when the operator explicitly asks it to (for example, adding a hotel booking or a competition schedule).

It is used by one person only — the operator himself — for personal scheduling. It is not a public service, has no sign-up, and is not distributed to third parties.

How it works

The app authenticates with Google OAuth 2.0 using the https://www.googleapis.com/auth/calendar scope. Authorisation tokens are stored locally on the operator's own device. No Google user data is sent to any external server, analytics service, or advertiser.
